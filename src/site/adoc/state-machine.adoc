= StateMachine (Interface)

The `StateMachine<S, IA, OA>` interface abstracts a machine with states (S), inputs (IA), and outputs (OA).
The central operation is `OA read(IA input)`.

JavaDoc summary:

- Represents a generic state machine with states, inputs, and outputs.
- `read(IA input)`: performs a transition based on the input symbol and returns the corresponding output.
- Contracts:
  * `input` must not be `null` (NullPointerException).
  * The input must be contained in the input alphabet (IllegalArgumentException for unknown symbols).

[source,java]
----
public interface StateMachine<S, IA, OA> {
    @NonNull
    OA read(@NonNull IA input);
}
----
