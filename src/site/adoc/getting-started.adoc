= Getting Started

This module provides a thread-safe finite state machine (FSM).
It supports Moore and Mealy semantics via factory methods.

== Installation

This module is part of the Foomp multi‑module build. Build the whole project or just the
`Automata` submodule with Gradle:

- Build entire project: `./gradlew build`
- Build Automata only: `./gradlew :Automata:build`
- Run tests for Automata: `./gradlew :Automata:test`
- Generate Javadoc: `./gradlew :Automata:javadoc`
- Optionally publish to local Maven: `./gradlew :Automata:publishToMavenLocal`

== Basics

- StateMachine<S, IA, OA>: generic interface with the operation `OA read(IA input)`.
- FiniteStateMachine<S, IA, OA>: implementation, thread-safe using a ReentrantLock.
- Moore automaton: output depends only on the current state.
- Mealy automaton: output depends on state and input.

== Example: Moore automaton

[source,java]
----
// States and alphabets
Set<String> states = Set.of("A", "B");
Set<Character> inputAlphabet = Set.of('0', '1');
Set<Integer> outputAlphabet = Set.of(0, 1);

// Transition function: (state, input) -> nextState
Fun2<String, Character, String> transition = (s, i) ->
    s.equals("A") && i == '1' ? "B" : "A";

// Moore output function: state -> output
Fun<String, Integer> output = s -> s.equals("B") ? 1 : 0;

// End states and initial state
Set<String> endStates = Set.of("B");
String initial = "A";

FiniteStateMachine<String, Character, Integer> fsm =
    FiniteStateMachine.mooreMachine(
        states, inputAlphabet, outputAlphabet,
        transition, output, endStates, initial
    );

Integer out1 = fsm.read('0'); // stays in A, output 0
Integer out2 = fsm.read('1'); // switches to B, output 1
boolean done = fsm.isInEndState(); // true when in B
----

== Example: Mealy automaton

[source,java]
----
// Output function: (state, input) -> output
Fun2<String, Character, Integer> output2 = (s, i) ->
    s.equals("A") && i == '1' ? 1 : 0;

FiniteStateMachine<String, Character, Integer> mealy =
    FiniteStateMachine.mealyMachine(
        states, inputAlphabet, outputAlphabet,
        transition, output2, endStates, initial
    );

int out = mealy.read('1'); // output depends on (state, input)
----

== Thread safety

All state transitions are guarded by a ReentrantLock. The instance is therefore thread-safe.

== Error handling and localization

Known error conditions (e.g., empty sets, unknown tokens) are validated and described with localized
messages from `AutomataMessages`.
